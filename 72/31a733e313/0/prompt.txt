Add automated 7am daily email alert 
with Gemini AI and enable/disable 
toggle in settings.

ENVIRONMENT VARIABLES ALREADY IN .env.local:
- RESEND_API_KEY
- ALERT_FROM_EMAIL
- ALERT_TO_EMAIL
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- GEMINI_API_KEY

PART 1 — SETTINGS TOGGLE
In app/settings/page.js add to 
Alert Preferences section:

Automated Daily Alert card:
- Title: Automated Daily Alert
- Description: Automatically send 
  compliance summary email every 
  morning at 07:00 AEST
- Large green toggle ON/OFF
- When ON: green badge showing
  Active — sends daily at 07:00 AEST
- When OFF: grey badge showing
  Disabled — manual alerts only
- Save to localStorage: cm_autoAlertEnabled
- Default: true
- Success toast when saved

PART 2 — INNGEST SETUP
Install inngest package first.

Create inngest/client.js:
- Create Inngest client with 
  id care-minutes-ai

Create inngest/functions/daily-alert.js:
- Schedule: 0 21 * * * 
  (9pm UTC = 7am AEST)
- Steps:
  1. Check cm_autoAlertEnabled
     If false → skip and return disabled
  2. Get facility and shifts from 
     lib/dummyData.js
  3. Calculate compliance using 
     calculateDayCompliance from 
     lib/compliance.js
  4. Get recipient email:
     First check cm_mgEmail localStorage
     Fallback to ALERT_TO_EMAIL env
  5. Build prompt for Gemini
  6. Call Gemini API with prompt
  7. Get AI generated message back
  8. Build HTML email with message
  9. Send via Resend
  10. Return success

Create app/api/inngest/route.js:
- Serve Inngest functions
- Export GET POST PUT handlers

PART 3 — GEMINI API INTEGRATION
In the daily alert function call 
Google Gemini API:

URL: https://generativelanguage.googleapis.com
     /v1beta/models/gemini-1.5-flash
     :generateContent
     ?key=process.env.GEMINI_API_KEY

Method: POST

Send this prompt to Gemini:
"You are a compliance analyst for 
Australian aged care facilities.
Write a short morning alert for the 
Director of Nursing.

Facility: [facility name]
Residents: [count]
Date: [DD/MM/YYYY]
Total care minutes: [X] of [target] ([%])
RN minutes: [X] of [target] ([%])
Status: [GREEN/AMBER/RED]
Penalty at risk: $[amount]

Shifts today:
[list each shift]

Rules:
- Maximum 80 words
- Use Australian English
- If GREEN: positive and reassuring
- If AMBER: suggest adding RN shift
- If RED: urgent tone, name staff to call
- Sound professional but friendly"

Parse Gemini response and extract 
the generated text.
